# URRC 자율주행 경진대회 — Monza · Hungaroring

## 1. 설치

지원 환경: **Ubuntu 24.04 / ROS 2 Jazzy / Gazebo Harmonic**. ROS 2 Jazzy 패키지 저장소가 구성된 Ubuntu에서 아래 명령을 한 번에 실행합니다.

```bash
sudo apt update && sudo apt install -y git unzip python3-venv cmake g++ libgz-sim8-dev ros-jazzy-ros-gz ros-jazzy-rqt-image-view python3-colcon-common-extensions
cd ~
git clone https://github.com/nahee2345/urrc_2.git
cd ~/urrc_2
source /opt/ros/jazzy/setup.bash
```

이미 다운로드한 경우에는 `cd ~/urrc_2 && git pull --ff-only`로 갱신합니다. Gazebo 그래픽 환경이 필요하며, 연습 차량이 있는 버전은 실행 시 C++ 플러그인을 자동 빌드합니다.

## 2. 실행방법

터미널을 열고 `cd ~/urrc_2`를 실행한 다음 **다음 네 명령어 중 하나만** 선택합니다.

| 맵 | 연습 차량 | 실행 명령어 |
|---|---|---|
| Monza | 없음 | `bash run_v10.sh monza` |
| Monza | 2대 | `bash run_pace_cars.sh monza` |
| Hungaroring | 없음 | `bash run_v10.sh hungaroring` |
| Hungaroring | 2대 | `bash run_pace_cars.sh hungaroring` |

- 두 맵 모두 기존 빨간 신호등 5개와 관전 카메라를 유지합니다.
- **연습 차량 2번 그리드:** 빨간색, **10 m/s**.
- **연습 차량 9번 그리드:** 파란색, **20 m/s**.
- 두 차량은 **각각 원래 그리드에서 출발**하며, 트랙 중앙으로 순간이동하지 않고 각자의 측면 주행 경로를 따라 계속 순환합니다.
- 두 연습 차량은 **빨간불 5개가 모두 꺼졌다는 확인 신호 이후** 동시에 출발합니다. 기존 신호등 로직을 유지합니다.
- 연습 차량은 참가자 차량이 아닌 **운영자 시연용 경로 추종 차량**입니다. 자율주행 센서 알고리즘이나 실제 조향·구동 물리 모델을 검증하는 용도가 아닙니다.
- 종료: 실행 터미널에서 `Ctrl+C`.

## 3. 자율주행차량 개발 및 대회 규정

### 개발 파일 위치

- **참가자가 개발한 차량 모델(URDF/SDF), 휠·센서 모델, 메시, ROS 2 패키지, 실행 파일, 주행 알고리즘, 설정 및 의존성 파일은 모두 `src/team_01/` 내부에 저장해야 합니다.**
- `src/team_01/` 밖에 위치한 참가자 소스·모델·설정은 **심사 및 제출 대상으로 인정하지 않습니다.**
- 배포되는 `src/team_01/`은 비어 있습니다. 참가자가 필요한 ROS 2 패키지와 디렉터리를 직접 작성합니다. GitHub에서 폴더를 유지하기 위한 `.gitkeep` 파일만 들어 있습니다.
- 맵·신호등·관전 카메라·운영자용 프로그램은 참가자가 수정하거나 대회 제출물에 포함해서는 안 됩니다.

### 차량 크기·장치

| 구분 | 최대값 또는 조건 |
|---|---|
| 차량 길이 | **0.55 m 이하** |
| 차량 너비 | **0.25 m 이하** |
| 차량 높이 | **0.18 m 이하** |
| 최대 조향각 | **좌우 각각 35° 이하** |
| 센서 종류 | 제한 없음 |
| 센서 개수 | 제한 없음 |
| 연석·방호벽 높이 | **0.30 m** (시뮬레이션 맵 기준) |

- 차량 최대 규격에는 **바퀴, 모든 센서, 카메라, LiDAR, 하우징 및 돌출 구조물**을 포함합니다.
- 물리 충돌체(`collision`)는 실제 시각 모델(`visual`)의 차량 외형을 정확하게 반영하거나 그 이상을 감싸야 하며, 보이지 않는 축소 충돌체를 사용하는 것은 허용하지 않습니다. **물리 충돌체도 최대 차량 규격을 초과해서는 안 됩니다.**
- 실제 물리 엔진의 주행·접촉·충돌 판정이 시각 효과보다 유리하도록 약화되어서는 안 됩니다.
- 차량의 주행 제어는 제출된 `src/team_01/`의 알고리즘으로 수행해야 합니다. 트랙 또는 차량의 위치를 순간이동시키는 방식은 인정하지 않습니다.

### 1번 출발 그리드 좌표

좌표 단위: m. Yaw는 라디안이며 `x y z yaw` 순서입니다. 스폰 높이는 차량의 모델 원점과 노면 접촉 높이를 고려해 참가자가 설정합니다.

| 연습 맵 | X | Y | 노면 Z | Yaw (rad) |
|---|---:|---:|---:|---:|
| **Monza** | 0.378672 | -2.056035 | 1.203527 | 1.457384 |
| **Hungaroring** | 2.032524 | -0.658216 | 6.397033 | 2.469082 |

이 좌표는 배포된 `src/urrc_track_gazebo/tracks/processed/<맵이름>.json`의 **1번 그리드**를 기준으로 합니다. 단독 연습에서 참가 차량은 1번 그리드에서 출발합니다.

### 필수 주행 기능

- 앞에서 달리는 차량을 감지하고 **충돌 없이 회피·우회하여 추월하는 주행 알고리즘**을 반드시 포함해야 합니다.
- 센서는 종류와 개수에 제한이 없지만, 자율주행 판단과 제어는 참가자의 `src/team_01/` 내부 코드에서 수행해야 합니다.
- 신호등의 **빨간불 5개가 모두 꺼진 후에만 출발**할 수 있어야 합니다.

### 실격 규정

1. **빨간불 5개가 전부 꺼지기 전에 움직이거나 출발하면 실격**입니다.
2. **첫 번째 빨간불이 켜진 시점부터 20초 이내에 출발하지 못하면 실격**입니다. 단, 전체 소등 전 출발은 금지되므로 두 조건을 동시에 준수해야 합니다.
3. **뒤에서 앞차를 추돌하면 실격**입니다. 추월·우회 시에도 충돌 없이 진행해야 합니다.
4. 도로변 **연석·방호벽에 접촉하는 것은 실격 사유가 아닙니다.**
5. 차량의 주행 높이가 주변 도로의 노면을 기준으로 **연석 상단 높이 0.30m보다 높아져 주행하면 실격**입니다(점프·부상·비행 방식 포함).
6. 차량 규격 초과, 조향각 초과, 제출 폴더 외부 알고리즘 사용, 시각 모델보다 축소된 물리 충돌체를 통한 부당한 통과도 실격 대상입니다.

> **운영 참고:** 위 항목은 대회 규정입니다. 현재 실행기만으로 모든 항목이 자동 실격 판정되는 것은 아니며, 운영자의 주행 영상·로그·차량 모델 검수가 필요합니다.
